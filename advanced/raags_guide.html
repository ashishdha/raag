How it works

Using the Raag Explorer

The Raag Explorer catalogs thousands of computationally-generated Hindustaanee raag candidates — from the handful everybody's heard performed, to obscure note-combinations nobody has named yet. This guide walks through every control on the page, in the order you'll actually reach for them: the Display menu first, then the two big note-based filter boxes, then the simpler filters underneath, then the custom filter builder, and finally the results table itself.

Four steps, if you're in a hurry
  1. Open Display (top right) and pick a notation system and how many columns to show.
  2. Use Present Svar / Varjit Svar to describe which notes a raag should, or shouldn't, use.
  3. Narrow further with Status, Dimension, and Jaati — or just search a name or ID.
  4. Need something more specific? Set Filter preset to Custom, add filters, then click Apply.

1 The Display menu

The Display button in the top right of the Raag Explorer opens a small panel with three settings. None of them filter anything — they only change how results look, so feel free to experiment freely.

Notation

Every raag is built from svar drawn from twelve possible svarsthaan per octave. The Notation dropdown decides how those are written on screen:

  • Hindustaanee Sargam — the native notation used throughout Hindustaanee classical music: S r R g G M m P d D n N.
  • Integers — the same twelve positions written as plain numbers, 0 through 11.
  • Jazz Scale Degrees — the degree numbers used in jazz theory.
  • Western (in C) — ordinary letter names (C, D, E…), treating Sa as C.
  • Carnatic Sargam — the equivalent solfège used in Carnatic (South Indian classical) music.

Switching notation is instant and never changes which raags are shown — only how their aaroh and avaroh are written.

Columns

This dropdown controls how many metrics are shown per raag, from Minimum (just the name and the aaroh/avaroh) up to Maximum (every metric the database tracks). Each level is cumulative — Standard shows everything Minimum and Contracted show, plus more:

  • Minimum — name, aaroh, avaroh.
  • Contracted — adds the Scientific ID badge, thaat, jaati in each direction, and a couple of purity/consonance scores.
  • Standard — adds symmetry, dimension, ang balance, and note-relationship chains.
  • Expanded — layers in note-level detail: the full svarset, imperfect and detached svarsthaan, and jump sizes between consecutive notes.
  • Maximum — unlocks everything left: variant-switching counts, poorvaang/uttaraang splits for the combined svarset and each direction separately, and the internal Row ID housekeeping column.

The Scientific ID badge appears from Contracted upward; the Row ID number is reserved for Maximum, since it's really only meaningful for database bookkeeping.

Filter preset

A shortcut for common starting points — All raags, Named only, Unnamed only, 1D · Identical, 2D · Different — each of which applies immediately. Choosing Custom instead reveals the custom filter builder (see Section 4 below); it won't change your results by itself until you've added at least one filter and clicked Apply.

2 Present & Varjit Svar

These two boxes are the heart of the page — they describe a raag by which notes it uses, independent of any specific name or thaat. Present Svar asks for notes that must appear in the aaroh (ascent) and/or avaroh (descent). Varjit Svar — literally the "forbidden" notes — asks for notes that must be missing. Each box has the same pair of toggles, plus a shared Both button.

Specific vs. Generic

In Hindustaanee sargam, letter case carries meaning: an uppercase letter is the shuddha (natural) form of a note, and a lowercase letter is the altered form — komal (flatter) for Re, Ga, Dha and Ni. Ma is the one exception, since it has no komal version: uppercase M is shuddha Ma, and lowercase m is teevra (sharp) Ma instead.

  • Specific respects this distinction — typing r matches only komal Re, and R matches only shuddha Re.
  • Generic ignores it — typing either r or R simply means "the Re family," matching a raag whether it uses the komal or the shuddha version. There are seven such families: Sa, Re, Ga, Ma, Pa, Dha, and Ni.

Inclusive vs. Exclusive

For Present Svar: Inclusive means at least these notes — everything you type must appear, but other notes are still allowed. Exclusive means only these notes — the aaroh (or avaroh) must be built from precisely what you typed, and nothing else.

For Varjit Svar the same two words describe what's absent instead: Inclusive means at least these notes are missing — everything you type must be dropped, though the raag may drop others too. Exclusive means only these notes are missing — the raag must be missing exactly what you typed, with every other note present.

Example · Present, Generic + Inclusive

To find every raag whose ascent uses Ga in some form, without caring about anything else: set Present Svar to Generic + Inclusive, turn Both off, and type G into the Aaroh box only.

Example · Present, Specific + Exclusive

To find raags whose ascent is built from exactly the shuddha, major-scale notes and nothing else: set Present Svar to Specific + Exclusive and type S R G M P D N into the Aaroh box.

Example · Varjit, Generic vs. Exclusive

Typing D d into Varjit Svar under Generic + Inclusive finds raags that drop Dha entirely, in either form — they might drop other notes too. Switching to Exclusive with just D typed instead finds raags missing exactly shuddha Dha, and nothing else.

Both

The Both button mirrors whatever you type in the Aaroh box into the Avaroh box, and vice versa — handy when your criteria should apply symmetrically in both directions. Turn it off to set the ascent and descent independently. Present Svar starts Exclusive + Specific with Both on; Varjit Svar starts Inclusive + Generic with Both on — reasonable defaults for most searches, but every combination is available.

3 Status, Dimension & Jaati

Below the two svar boxes sit a handful of simpler filters.

Status

Named / Unnamed / All. This database includes every scale combination that survives the validity rules — not just raags with an established identity — so many rows are still waiting to be named. Status lets you show only the ones that already have a name, only the unnamed candidates, or everything.

Dimension

Describes how a raag's aaroh and avaroh relate to each other:

  • Identical — the same notes, same shape, in both directions.
  • Different — a different note-set ascending versus descending.
  • Vakra — zigzag movement, where notes appear out of strict order.
  • JoD — a raag built by joining two distinct fragments.
  • Raagish — a borderline case: more raag-like than a plain scale, but not fully confirmed as a raag.

Most entries in the database today fall under Identical or Different; the remaining categories are reserved as the classification work continues.

Aaroh Jaati / Avaroh Jaati

Jaati counts how many of the seven svar families appear in a given direction. The classical terms for the common cases are Audav (five notes), Shadav (six notes), and Sampoorna (all seven — complete); rarer raags can use as few as three or four. Pick Min, Exactly, or Max, then a note count, to filter on either direction independently.

Name / ID

A plain text box — type any part of a raag's name, or its row number, to jump straight to it.

4 Custom filters

For anything the controls above don't cover, switch Filter preset (in the Display menu) to Custom. This reveals a builder that can filter on almost any column the database tracks — over fifty of them, from Symmetry Score to Samvaad at Pa to which Moorchhanaa family or Thaat a raag belongs to.

Adding a filter

Click + Add filter to add a row. Each row has three parts:

  • Column — grouped the same way as the Columns menu (Minimum, Contracted, Standard, Expanded, Maximum), so if you can't find what you're after, it's probably filed under a later group. You don't need to raise the Columns setting to filter on something — filtering and display are independent. If you also want to see the column's values in the table, raise Columns to match separately.
  • Comparison — the choices adapt to the column's type. Number columns offer Min / Max / Exactly / Less than / More than. Text columns offer Contains / Starts with / Exactly. Note-array columns (like Svarset or Varjit Svar) offer Contains / Excludes, read the same way as the sargam letters in Present/Varjit Svar above. A handful of columns — Thaat, Ang, Samay, Creator, Popularity, and similar fixed categories — skip the comparison entirely and just offer a dropdown of exact values.
  • Value — the input itself, shaped to match whatever comparison is selected.

Click the × to remove a row. Stack as many filters as you like — a raag has to satisfy every single one, together with anything set in Present/Varjit Svar and the quick filters above, before it appears. Nothing takes effect until you click Apply.

5 Reading & sorting the table

The table shows one row per raag, with columns matching whichever visibility level is selected in Display.

The Scientific ID

From Contracted upward, the first column is a compact, color-coded badge rather than plain text — a fingerprint for the row. It's built from four segments: the aaroh's underlying scale code (blue, four digits), the avaroh's underlying scale code (purple, four digits), the dimension digit (grey), and an instance number (green) that only changes if two different raags ever end up sharing the exact same aaroh, avaroh, and dimension.

Sorting

Click any column header to sort the whole table by that column, ascending. Click it again to reverse to descending. A small triangle marks whichever column is currently driving the sort order. Sorting only reorders the rows you can already see — it never hides or reveals anything; that's what the filters above are for.

Scrolling

At higher visibility levels there are far more columns than fit on screen, so the table scrolls sideways as well as up and down — the column headers stay pinned in place while you scroll down, and a highlighted scrollbar along the bottom lets you pan across. The footer below the table always shows how many raags are currently showing, out of the total.
